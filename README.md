# 💈 Barbearia

Projeto de site para barbearia desenvolvido com foco em prática de HTML, CSS e JavaScript, aplicando estrutura de layout, responsividade e interações de interface.

---

## 🎯 Objetivo

Este projeto foi desenvolvido com o objetivo de treinar estruturação de páginas web, organização de código e prática de desenvolvimento front-end, simulando um site real de negócio local.

---

## 🚀 Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript (Vanilla)

---

## ⚙️ Funcionalidades

- Página inicial com apresentação da barbearia  
- Seção de serviços e preços  
- Galeria de imagens  
- Sistema de agendamento  
- Layout responsivo para mobile e desktop  
- Navegação entre seções
